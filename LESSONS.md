# Lessons for KOML

The domain needs an explicit definition of unfinished and important. A priority alone is insufficient: the reference date and terminal statuses determine whether a task needs evening closure. Blocked tasks remain unfinished, and future due dates are valid rather than malformed.

Validated by synthetic evidence: explicit due dates, priorities and statuses support exact deterministic classification of 200 planted records, including every qualifying ID with no false positives. Changing a qualifying record to done changes both closure and blocked counts, showing the result is computed. The assumption that this rule captures Henry's actual evening concerns remains untested until real use.

Operating rule for future builds: define the decision rule and independent labelled truth before claiming accuracy, and separate synthetic acceptance from evidence of real usefulness. Never fill an evidence window with invented adoption or savings.
